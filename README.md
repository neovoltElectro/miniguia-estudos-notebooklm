## Engenharia de Prompts

### Prompt 1 – Resumo da documentação

**Pergunta:** Faça um resumo da documentação do Bootstrap 5.

**Resumo da resposta:**
O Bootstrap 5 é um framework front-end que facilita o desenvolvimento de interfaces responsivas. A documentação apresenta sua configuração inicial, o sistema de Grid, componentes prontos, opções de personalização com CSS/Sass e diversos exemplos de layouts.

**Aprendizado:**
Compreendi a estrutura geral do Bootstrap e os recursos que ele oferece para acelerar o desenvolvimento de páginas web.

---

### Prompt 2 – Componentes que utilizam JavaScript

**Pergunta:** Quais componentes do Bootstrap 5 precisam de JavaScript para funcionar?

**Resumo da resposta:**
Alguns componentes dependem do JavaScript do Bootstrap, como Navbar responsiva, Carousel, Modal, Dropdown, Collapse, Offcanvas, Tooltips, Popovers, Toasts e Scrollspy. Alguns também necessitam da biblioteca Popper para posicionamento.

**Aprendizado:**
Aprendi que nem todos os componentes funcionam apenas com CSS, sendo necessário incluir os arquivos JavaScript em projetos que utilizam recursos interativos.

---

### Prompt 3 – Componentes para Landing Pages

**Pergunta:** Quais componentes são essenciais para criar uma landing page?

**Resumo da resposta:**
Os principais componentes são Navbar, Hero, Cards, Buttons, Forms, Accordion, Carousel e Footer, organizados através do Grid System para garantir responsividade.

**Aprendizado:**
Passei a entender quais componentes utilizar para estruturar uma landing page completa e organizada.

---

### Prompt 4 – Sistema de Grid

**Pergunta:** Como funciona o sistema de Grid do Bootstrap 5?

**Resumo da resposta:**
O Grid utiliza Flexbox e segue a abordagem mobile-first. Sua estrutura é formada por Containers, Rows e Columns, além de breakpoints para adaptar o layout a diferentes tamanhos de tela.

**Aprendizado:**
Aprendi como organizar páginas responsivas utilizando containers, linhas, colunas e breakpoints.

## Miniguia de Estudo

### O que é Bootstrap?

Bootstrap é um framework front-end que fornece componentes prontos e um sistema de Grid responsivo, permitindo criar interfaces modernas de forma rápida.

### Sistema de Grid

O Grid utiliza Flexbox e organiza o layout através de Containers, Rows e Columns, adaptando-se automaticamente aos diferentes tamanhos de tela.

### Componentes Principais

- Navbar
- Cards
- Forms
- Buttons
- Accordion
- Carousel
- Footer
- Modal

### Responsividade

O Bootstrap segue a abordagem Mobile-first e utiliza Breakpoints para adaptar o layout conforme a resolução da tela.

### Personalização

É possível personalizar o framework utilizando CSS, Variáveis CSS e Sass.


### Glossário

| Conceito | Descrição |
|----------|-----------|
| **Bootstrap** | Framework front-end que facilita a criação de interfaces responsivas e modernas. |
| **HTML** | Linguagem de marcação utilizada para estruturar páginas web. |
| **CSS** | Linguagem responsável pela estilização e aparência dos elementos HTML. |
| **Grid System** | Sistema de layout baseado em Flexbox que utiliza containers, linhas e colunas para criar páginas responsivas. |
| **Container** | Elemento que centraliza e organiza o conteúdo da página. |
| **Breakpoints** | Pontos de interrupção que adaptam o layout para diferentes tamanhos de tela. |
| **Accordion** | Componente que permite expandir e recolher seções de conteúdo. |
| **Collapse** | Plugin JavaScript utilizado para mostrar ou ocultar elementos. |
| **JavaScript** | Linguagem que adiciona interatividade aos componentes do Bootstrap. |
| **Popper** | Biblioteca utilizada pelo Bootstrap para posicionar Dropdowns, Tooltips e Popovers. |
| **Sass** | Pré-processador CSS que permite personalizar o Bootstrap de forma mais avançada. |
| **Mobile-first** | Estratégia de desenvolvimento que prioriza dispositivos móveis antes de telas maiores. |
| **Viewport** | Meta tag responsável por garantir a responsividade em dispositivos móveis. |
| **Reboot** | Conjunto de estilos do Bootstrap que padroniza a aparência entre navegadores. |
| **CDN** | Serviço que permite utilizar o Bootstrap sem precisar instalar os arquivos localmente. |
